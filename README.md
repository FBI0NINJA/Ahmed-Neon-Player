# Ahmed Neon Player

Modern Neon Music Player built with C++ and Raylib.

## Overview

Ahmed Neon Player is a stylish and modern music player designed for both desktop and mobile devices. The project uses a dark neon UI inspired by modern gaming and next-generation application designs.

The application is lightweight, fast, responsive, and completely free to build and use.

---

# Features

* Modern Neon User Interface
* Dark Mode Design
* Music Playback
* Play / Pause Controls
* Next / Previous Buttons
* Volume Control
* Progress Bar
* Smooth Animations
* Responsive Window Size
* Lightweight Performance
* Designed for Desktop and Mobile
